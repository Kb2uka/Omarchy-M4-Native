# Updates: 15-inch M4 MacBook Air tester build

This tester build does not connect to M4 updates. The update channel serves
the 13-inch M4 Air only, and its setup refuses the 15-inch Air, so this build
does not try it. Do not run `omarchy-m4-update` or the 13-inch Air's
`m4-connect.sh` line here.

A fixed tester build, if one is needed, is published as a new release linked
from issue #142. Install it the same way, from macOS.
