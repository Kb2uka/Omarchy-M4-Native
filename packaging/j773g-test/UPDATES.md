# Updates: M4 Mac mini tester build

This tester build does not connect to M4 updates. The update channel serves
the 13-inch M4 Air only, and its setup refuses the Mac mini, so this build
does not try it. Do not run `omarchy-m4-update` or the Air's `m4-connect.sh`
line here.

A fixed tester build, if one is needed, is published as a new release linked
from issue #136. Install it the same way, from macOS.
